# ColorShower playground

This app demonstrates the published ColorShower package using TypeFox Monaco. Its content comes from the root [docs](../../docs/) and [examples](../../examples/) directories, following the MoyaForge app/content separation. Do not duplicate product documentation or examples in `apps/playground`.

From the repository root, run `npm run dev` to build ColorShower and start Vite. See [development documentation](../../docs/development/README.md) for setup and tests.
